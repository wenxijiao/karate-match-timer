# Match-day operator guide

## Before participants arrive

1. Connect power and the external displays. Use extended displays so the controls stay on the operator's computer.
2. Confirm the event's timing and scoring arrangements with the instructor or referee. Regular time defaults to two minutes and extra time to one minute; these are editable presets.
3. Select the audience screens. The desktop applications can show a timer and a separate scoreboard. The browser version shows a timer only.
4. Enter an event title and, on desktop, the competitor names or side labels.
5. Test the bell through the actual speakers. In the Windows application, the time-up bell and scoreboard are off by default.
6. Run a short rehearsal: start, pause, resume, time up, reset, score correction and the next bout.

## During a bout

Use Space to start, pause or resume. The timer changes colour in the final ten seconds and shows **TIME UP** when it finishes. Use the control buttons to adjust time while paused.

On desktop, Q / W / E add 1 / 2 / 3 points to AKA; I / O / P do the same for SHIRO. Use -1 to correct a score. A timer reset preserves scores. A new bout resets the timer and clears the scores after confirmation.

A referee or event official decides when timing should stop, which points to award and whether extra time is needed. The software carries out the operator's actions.

## If something interrupts the event

- **Accidental exit:** reopen the application and check the recovered time and scores with the official before resuming. Saved time may trail the last displayed time by roughly a second.
- **Disconnected monitor:** check the controls and reconnect the display. Open the audience windows again and verify the correct screens before continuing.
- **Browser controls reloaded:** close the old audience window and reopen it from the controls. The audience connection warning is informational and does not stop the match for you.
- **Audio problem:** use the visual time-up indicator and check the selected speaker output. In Windows, a missing music file can be reselected or disabled with **Countdown only**.

Keep the machine powered and avoid manual sleep or lid closure during a bout. The applications' wake requests do not replace a rehearsal with the actual equipment.

## Privacy

Names, scores and settings stay on the operator's computer. The applications do not send them to a server. Do not add event records, participant names or personal audio files to the source repository.
